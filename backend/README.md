# Backend: Dual-Write Epic Creation Service\n\n## Overview\n\nThis module implements and validates the dual-write pattern for persisting epic data to both Jira and DynamoDB simultaneously.\n\n## Architecture\n\n```\n+------------------+     +------------------+     +------------------+\n|   Workflow        |     |   Jira           |     |   DynamoDB       |\n|   System          | --> |   (Primary)      |     |   (Secondary)    |\n|                   |     |                  |     |                  |\n+------------------+     +------------------+     +------------------+\n         |                       ^                       ^\n         |                       |                       |\n         v                       |                       |\n+------------------+             |                       |\n| EpicDualWrite    |-------------+-----------------------+\n| Service          |  Writes to both stores concurrently\n+------------------+\n```\n\n## Key Components\n\n### EpicDualWriteService\n- Orchestrates writes to both Jira and DynamoDB\n- Implements retry logic (configurable, default 3 attempts)\n- Logs all operations with correlation IDs\n- Handles partial failures gracefully\n- Provides consistency verification\n\n### Error Handling\n- **Jira failure**: DynamoDB write still proceeds; failure logged with correlation ID\n- **DynamoDB failure**: Jira write still proceeds; failure logged with correlation ID\n- **Both fail**: Total failure logged at CRITICAL level; operation recorded for retry\n- All errors include: ticket_id, correlation_id, attempt count, error details\n\n### Consistency Verification\n- `verify_consistency(ticket_id)` checks both stores for matching data\n- Compares: title, description, status, ticket_id\n- Reports discrepancies for investigation\n\n## Running Tests\n\n```bash\n# Run all dual-write tests\npython -m pytest backend/tests/ -v\n\n# Run specific test file\npython -m pytest backend/tests/test_dual_write_epic.py -v\n\n# Run validation report\npython -m pytest backend/tests/test_dual_write_validation_report.py -v\n```\n\n## Ticket Reference\n- Workflow: wf_1779334880119_jekzv5\n- Epic: TEAM-110\n- Ticket: TEAM-123\n
